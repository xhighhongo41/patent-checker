# Patent Checker

Search published patents related to your own software project and generate a
survey report (best effort). This tool does **not** determine infringement and
is not a substitute for professional legal advice.

**Status: pre-release (v0.2, local toolchain).** This version provides the
core library, the `patent-checker` CLI (EPO OPS + Google Patents access,
screening utilities, consent gate), and the Agent Skill under `skills/`.
The MCP server, caching, and packaged distribution are planned for later
versions; installation instructions will follow with the first public
release.
